Baby-Gear · Redesign exploration

Landing layout — make the comparison grid the page

The summary view today buries its best artifact. This study explores a grid-first shell: drop the sticky left rail and the button row, give the comparison grid 90%+ of the screen, move between modules with tabs above the grid, and push navigation into a hamburger and context into a thin header. Five layout variants, then three analogous problem spaces that already solve "dense table as the primary surface" well. Grids are populated with the real seed cohort (infant car seats), persona: $500 budget · back seat 28″ · owns a BOB Wayfinder.

Sticky left nav — eats width, low-value on a single-surface tool
Hamburger drawer for nav; off-canvas, summoned only when needed
Button row across the top — noisy chrome competing with the data
Minimal header: brand + context; actions fold into an overflow menu
Contained, centered column — the grid is cramped at ~50% width
Edge-to-edge grid, sticky header row + frozen option column, dense but legible
Modules hidden in the rail
Module tabs directly above the grid; scrollable popover for the per-row breakdown

Part A — Five landing-layout variants

One 48px header (hamburger · brand · live limit chips · match legend · overflow ⋯), then a segmented control for modules sitting on a thin rule. Everything below is the grid, edge-to-edge with a sticky head and a frozen option column. The safe, balanced default.

Part B — Three analogous problem spaces

Mature products that already treat a dense comparison table as the primary surface, with tabbed sections and minimal chrome. Each notes the one pattern worth stealing.

B1Flight search (Google Flights / Kayak)

Results are the page. A thin search summary header, sort tabs (Best / Cheapest / Fastest), and a row of filter chips — then an edge-to-edge list where each row exposes the real trade-off values (price, duration, stops).

The reference for respectful density: hundreds of cells, frozen ticker column + sticky header, every column sortable, and color that encodes the value itself (green/red heat) so a glance finds the outliers. Sector tabs switch the universe.
