# Clek-Compatible Strollers — Full Roster (all 80 rows, nothing dropped)

Every model row from Clek's official list ([`_CLEK_LIST.md`](_CLEK_LIST.md)) gets
a stable `id` (= fragment filename = image filename = seed.json option id) and a
**batch** (grouped by brand so a session shares DTC pages). `adapterIds` link to
[`../adapters/_ROSTER.md`](../adapters/_ROSTER.md). Single/Double modes of the
same stroller are kept as separate rows (per "don't reduce the list") — they
share physical specs but differ in adapter, so record both.

**Count: 80 strollers across 24 brands → 10 batches (S1–S10).**
