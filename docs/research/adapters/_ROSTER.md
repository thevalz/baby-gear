# Car-Seat Stroller Adapters — Full Roster (deduped from the 80 stroller rows)

Every distinct adapter SKU that connects the Clek Liing/Liingo to a listed
stroller. Deduped: many strollers share one adapter. Each gets a stable `id`
(= fragment filename = image filename = seed.json option id) and inherits the
**brand batch** of the strollers it serves (so one session sources a brand's
strollers **and** its adapters together — same DTC pages).

`madeBy`: **brand** = made by the stroller brand (Maxi-Cosi-style footprint) ·
**Clek** = Clek-made (UPPAbaby CRUZ/Vista only). `disc.` = Clek's list flags the
adapter discontinued (verify a current replacement). **58 distinct adapters.**
